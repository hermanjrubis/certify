Got questions?

Frequently asked questions

Are my certificate images or recipient names uploaded anywhere?

No. Certify runs entirely in your web browser. Your template image, names, and spreadsheet data stay on your machine and are never transmitted to any server.

Can I use multiple spreadsheet columns like “Honor” or “Date”?

Yes! When you import a CSV, any column can be referenced in any text layer using {ColumnName} syntax. You can also create separate text layers for each column.

What file formats can I upload and export?

You can upload templates in PNG, JPG, or WebP up to 20MB. Certify exports all certificates as full-resolution, lossless PNG files packaged into a single ZIP archive.
